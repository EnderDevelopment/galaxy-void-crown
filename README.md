# Galactic Void Crown

Galactic Void Crown is a Minecraft texture pack that features a void skin with a galaxy on the front and back, and a black crown. This pack is designed for players who want a unique and visually appealing skin that stands out in the game.

## Install

1. Download the texture pack from the GitHub repository or the EnderDevelopment marketplace.
2. Open Minecraft.
3. Go to the "Options" menu.
4. Click on "Resource Packs".
5. Click on the "Open Resource Pack Folder" button.
6. Drag and drop the downloaded texture pack into the folder.
7. Go back to the "Resource Packs" menu.
8. Enable the texture pack by clicking on the checkbox next to it.

## Use

1. Launch Minecraft.
2. Go to the "Skin Customization" menu.
3. Click on the "Upload Skin" button.
4. Select the `void_galaxy_crown.svg` file from the downloaded texture pack.
5. Click on the "Upload" button to apply the skin.
